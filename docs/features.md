# 已支持与不支持功能

本文记录 CloudWarden 的 Bitwarden 兼容边界。当前版本面向个人使用，优先保证官方客户端的基础登录、同步和密码库增删改查。

## 已支持

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 用户注册/登录 | 已支持 | `POST /api/accounts/register`、`POST /identity/connect/token` |
| 刷新令牌 | 已支持 | `grant_type=refresh_token` |
| 密码库同步 | 已支持 | `GET /api/sync` |
| 登录项 | 已支持 | 密文字段原样保存 |
| 安全笔记 | 已支持 | 密文字段原样保存 |
| 银行卡 | 已支持 | 密文字段原样保存 |
| 身份信息 | 已支持 | 密文字段原样保存 |
| 文件夹 | 已支持 | 创建、更新、删除、同步 |
| 收藏和删除状态 | 已支持 | 支持 favorite、软删除、恢复、永久删除 |
| 附件 | 已支持 | 元数据在 D1，对象在 R2 |
| Send | 已支持 | 支持基础 text/file 元数据和同步 |
| Bitwarden 批量导入 | 已支持 | `POST /api/ciphers/import`，适配客户端导入流程 |

## 暂不支持或不建议依赖

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 企业组织完整能力 | 暂不支持 | 包括复杂成员、策略、权限模型 |
| SSO | 暂不支持 | 不作为个人服务核心目标 |
| SCIM | 暂不支持 | 企业用户生命周期管理 |
| Emergency Access | 暂不支持 | 紧急访问流程复杂，需额外安全设计 |
| 官方 Web Vault 完整兼容 | 暂不支持 | 优先兼容客户端常用 API |
| 邮件发送 | 待定 | 如支持邀请、验证码或通知，需要 SMTP 配置 |
| 多租户隔离 | 不建议依赖 | 当前目标是单实例个人使用 |
| 实时推送通知 | 暂不支持 | 当前返回空 negotiate，依赖客户端手动或周期同步 |
| 官方 Web Vault 托管 | 暂不支持 | 当前交付的是兼容 API 服务，不内置 Web Vault 前端 |

## 兼容性原则

- 优先保证官方 Bitwarden 桌面端、浏览器扩展和移动端的基础登录、同步、增删改查。
- 对无法完整实现的企业功能，应明确返回错误，避免客户端误以为操作成功。
- 涉及加密、密钥派生和同步修订号的逻辑，应优先匹配官方客户端预期。
- 服务端不解密 vault 内容，登录项、卡片、身份、笔记等加密 JSON 字段按客户端提交内容原样保存。

## 发布前检查清单

- 登录、同步、创建、编辑、删除至少在一个桌面客户端和一个浏览器扩展中验证。
- `npm test` 通过。
- D1 迁移可以从空库完整应用。
- R2 附件上传和下载可用。
- 关闭开放注册时，新用户无法自行注册。
- Worker 日志中不输出主密码、令牌、密码库明文或导入 JSON 内容。
